# 画布面板 / Canvas panel

在 DeepSeek Harness Web GUI 的对话旁加一列画布：模型产出的交付物直接在这里看，划选、点选或框选之后，标注按编号一次性回填到输入框。

```text
┌──────────┬──────────────────────────────┬──────────────────┐
│ 工作区   │  画布（交付物 + 标注）        │  对话            │
│ ▸ 目录   │  notes.md | hero.html | ▣   │  用户 / 模型     │
│ ▸ 文件   │  ─────────────────────────   │                  │
│          │  3. notes.md · 第 12-14 行 ✓ │  ┌────────────┐  │
│          │     > 这段话需要改写          │  │ 输入框     │  │
└──────────┴──────────────────────────────┴──────────────────┘
```

不访问外部网络，不写工作区以外的路径，标注只存在本机。

## 安装

```bash
# npm
dsh plugin --profile desktop add dsh-plugin-middle-panel

# 或从 Git 装（不依赖 npm）
plugin_manager install_bundle
target: git+https://github.com/Darkhe55/dsh-plugin-middle-panel.git
```

装完重启 DSH；界面没变化时按一次 `Ctrl+Shift+R` 硬刷新。

要求：DSH `>=0.2.2-rc.1 <0.3.0`，Node `>=24.9.0`，无运行时依赖。

## 快速开始

1. 让模型把产物交给你，它会调用 `canvas` 工具打开文件。
   ```json
   { "path": "demo/hero.html", "view": "auto", "note": "配色按设计稿改了" }
   ```
2. 在画布里标注：文本划选、HTML 悬停后点选元素、图片拖框、3D 点三角面、视频拖时间区间。
3. 每条标注写一句意见，点 **发送标注 (N)**，编号文本会填进输入框，补一句话发出去即可。

```text
以下是我在画布面板中的标注（共 2 条），请按编号逐条处理：

1. `demo/notes.md` — 第 5-6 行
   > - 第一条：这句话写得太平。
   意见：这里改成更具体的说法
```

处理过的条目标 `✓` 后保留编号，不再参与下一次发送。

也可以点会话头部右侧的 **画布** 按钮手动打开。

## 能看什么

| 类型 | 格式 | 标注方式 |
|---|---|---|
| 网页 | `.html` `.htm` | 悬停高亮、点选元素（选择器 + 文本）、暂停并逐帧 |
| 文本 | `.md` `.txt` | 划选行区间，可编辑保存 |
| 图片 | `.png` `.jpg` `.webp` `.gif` `.bmp` `.svg` | 框选区域、取色、标尺；SVG 可点选图层 |
| PDF | `.pdf` | 文字划选、框选区域；加密 PDF 可在面板内解锁 |
| Office | `.docx` `.xlsx` `.pptx` | 段落 / 单元格 / 分页文本 |
| 表格 | `.csv` `.tsv` | 单元格 |
| 三维 | `.stl` `.obj` `.ply` `.off` `.3mf` `.dae` `.glb` `.gltf` | 点三角面，带面片信息；重新导出后自动找回 |
| 视频 | `.mp4` `.m4v` `.webm` `.mov` `.ogv` `.ogg` | 时间区间 + 画面区域；逐帧、倍速 |
| 图纸 | `.dxf` | 图元 |
| 其它 | `.doc` `.xls` `.ppt` `.step` `.dwg` `.fbx` 等 | 明确提示需转换，不显示乱码 |

超大文件会被拒绝并说明原因（模型预览上限 192 MB），不会让面板失去响应。

## 面板操作

| 操作 | 说明 |
|---|---|
| `?` | 快捷键与设置 |
| `Ctrl+Tab` | 切换标签（加 `Shift` 反向） |
| `Alt+W` | 关闭当前标签 |
| `Alt+\` | 并排对比，再按一次收起 |
| `Alt+1` / `Alt+2` | 在并排的两个窗格间切换焦点 |
| `Esc` | 先退出并排，再关闭帮助 |
| `Alt+S` | 暂停 / 继续（HTML 动画、视频） |
| `Alt+A` / `Alt+D`、`←` / `→` | 后退 / 前进一帧 |
| `F` | 复位取景（3D） |
| `1`-`7` | 前后左右顶底 / 等轴测（3D） |

并排对比：拖分隔条调比例，窄于 860px 自动改为上下排列，标注仍属于文件而不是窗格。

## 设置

`?` 浮层里的**设置**页：

| 开关 | 默认 | 作用 |
|---|---|---|
| 新产物自动打开 | 开 | 模型产出新文件时，切到画布并选中该文件 |
| 记住路径 | 关 | 文件选择器下次回到上次目录 |
| 发送后清空 | 关 | 发送标注后清空列表 |
| 悬停高亮 | 开 | 悬停标注行时高亮画布中的位置 |
| 注入标注脚本 | 开 | HTML 预览内是否运行点选脚本 |
| 渲染调试计数 | 关 | 显示三角形 / 绘制计数 |

关闭「新产物自动打开」后，模型也不会再被提示主动打开画布（提示词与面板行为同步切换）。

这个开关同时是插件的**配置项**，所以在插件页的配置里也能改：改的是
`cordis.patch.yml` 中本插件行的 `config.autoOpenNew`，重启后仍然有效。
面板里的开关是同一个值的界面，改动会写回配置。

## 常见问题

| 现象 | 处理 |
|---|---|
| 保存提示 `413` | 请求体超过 6 MiB 或文件超过 4 MiB；改小内容或拆分文件 |
| 标签显示「文件不存在或已被移动」 | 文件被改名或删除，点「关闭标签」即可，磁盘上的文件不受影响 |
| PDF 打不开 | 加密文件会先要求密码；仍失败时点标签看提示的路径与大小 |
| 3D 画面空白 | 环境不支持 WebGL 时会给提示；也可在设置里关掉渲染调试计数再看 |

## 开发

```bash
node scripts/build.cjs    # 由 src/parts/ 生成 client.js
npm test                  # 全部测试
```

客户端改动刷新页面即可；宿主 `index.js` 改动需要重启 DSH。目录与实现说明见 [CHANGELOG.md](CHANGELOG.md) 与仓库内 `docs/internal/`（维护者资料，不在发布包里）。
